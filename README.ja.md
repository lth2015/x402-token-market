# AIネイティブ商取引インフラ

**Netstars × HABA — エンタープライズ向けAI使用量の計測・決済プラットフォーム**

> エージェントが働き続ける間、すべてのトークンが明確なビジネス記録になる。

[English](README.md) · [中文](README.zh.md)

---

## 課題

企業のAIエージェントは、価格分析・コンテンツ生成・物流比較といった実務を24時間休まず処理しています。

しかし現在のほとんどのAIプラットフォームは、次の3つの問いに答えられません：

- この処理にいくらかかったか？
- 残高が不足したとき、誰が補充するのか？
- AIサービスの利用料を、どうやって販売可能な製品にするか？

結果として、AIコストは管理不能のまま、商業化もできない状態が続いています。

---

## このプラットフォームについて

2つの製品、1つのビジネスストーリー。

### HABA Enterprise（エンタープライズ側）

越境EC事業者が、3つのルーティン業務をAIエージェントに委ねています：

- 競合価格調査とSKU値下げ・値上げ提案
- 新製品の英日バイリンガルコピー生成
- DHL / EMS / SALの配送時間・コスト比較

従来チームが毎朝2時間かけていた業務を、エージェントが深夜のうちに完了。翌朝9時、担当者がダッシュボードを開くと、すぐに活用できる結論がそこにあります。

**HABAエンタープライズダッシュボード**には、どのタスクが実行されたか、トークン残高はどう変化したか、エージェントが出した提案が何かがリアルタイムで表示されます。

### Netstars Tokenプラットフォーム（インフラ側）

AI使用量を計測可能・決済可能・製品化可能にするインフラ基盤。

HABAエージェントの全AI呼び出しはトークン台帳からリアルタイムに控除されます。残高が20%を下回ると、プラットフォームが自動的に補充を起動。x402プロトコルを介してSolana上でUSDC決済が実行され、人的承認なし、銀行送金不要で420ミリ秒で完了します。

**Netstars Token Console**では、プラットフォーム全体を俯瞰できます：月次売上トレンド・加盟店活動ランキング・AIモデル別呼び出し分布——AIコマースの事業収益が動く様子をリアルタイムで確認できます。

## ビジネス価値

| エンタープライズ顧客（HABA）| プラットフォーム事業者（Netstars）|
|---|---|
| AIエージェントが24時間稼働、人的監視が不要 | すべてのAI呼び出しが請求可能・監査可能なビジネスイベントに |
| トークン残高がリアルタイムで可視化、コストが透明 | 決済が自動完了、手動請求書発行が不要 |
| 自動補充により残高不足でエージェントが止まらない | プラットフォーム収益が加盟店のAI利用量に直結 |
| AIのコスト・成果・ROIを1つのダッシュボードで把握 | 次の加盟店にも展開できる再現可能なサービスモデル |

## プラットフォームアーキテクチャ

```
HABAエンタープライズ  →  Netstars Token API  →  x402ゲートウェイ  →  Wea決済ノード  →  Solana（USDC）
     （Next.js）              （FastAPI）           （FastAPI）         （Rust axum）
```

| サービス | 役割 | ローカルポート |
|---|---|---|
| HABA Enterprise | AIエージェントダッシュボード・トークン残高・自動補充 | 3001 |
| Netstars Token Console | 収益分析・加盟店ランキング・アクティビティフィード | 3000 |
| Netstars x402 Console | 決済プロトコルテレメトリ | 3002 |
| Wea Facilitator Console | オンチェーン決済テレメトリ | 3003 |
| token-api | AI使用量計測とトークン台帳 | 8080 |
| x402-api | 決済プロトコルゲートウェイ | 8081 |
| wea-api | Solana決済ファシリテーター | 8082 |

## デモシナリオ

| 場面 | 画面 | 操作 | 伝えたいこと |
|---|---|---|---|
| 1 · AIが稼働中 | HABA `/dashboard` | 3つのエージェントタスクを実行し、トークン残高のリアルタイム変化を見る | 本物のAI呼び出し、コストが即座に可視化 |
| 2 · 予算管理 | HABA `/budget` | 80%閾値ルールと予算ゲージを表示 | 企業がルールを設定し、AIが自律管理 |
| 3 · 自動決済 | HABA `/topup` | 補充履歴を確認し、Touch IDで承認 | x402がSolana上で420msで決済、人間不要 |
| 4 · 朝のレポート | HABA `/dashboard` | エージェントの成果物とトークン残高の回復を表示 | 深夜の業務が、翌朝すぐ使える結論に |
| 5 · プラットフォーム視点 | Netstars `/revenue` + `/merchants` | 月次売上トレンドと加盟店活動ランキング | 各加盟店のAI利用がNetstarsの事業収益に直結 |
