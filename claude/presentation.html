TECHNOLOGY CORE

X402 协议：为机器设计的支付语言

📡 协议本质

X402 是基于 HTTP 402 状态码的机器可读支付协议。 当 Agent 访问需要付费的资源时，服务端返回 402 + 支付要求， Agent 自动完成支付后重发请求——全程无需人工介入

⚡ 核心优势

  • 🔹 小额高频：单笔费用可低至 $0.001，适配 Token 计费
  • 🔹 无损结算：链上 USDC，无汇率损耗，实时到账
  • 🔹 标准化：HTTP 原生，任何语言/框架无缝集成
  • 🔹 可审计：每笔链上存证，全程可追溯

🔄 X402 交互时序

Agent → GET /api/ai-service
Server ← 402 Payment Required
       { amount: 0.01 USDC, addr: "..." }
Agent → (自动) 链上支付 USDC
Agent → GET /api/ai-service + payment-proof
Server ← 200 OK + 服务数据
DEMO STORY

一个 Agent，从零到完成商业任务

场景设定：一家日本电商公司部署了一个"智能商品分析 Agent"， 每天自动抓取竞品数据、生成价格策略报告，并通过 AI 生成营销文案。 这些任务都需要消耗 AI Token——而公司希望 Agent 能自主完成充值与支付，无需人工干预。

1

Agent 检测到 Token 余额不足

Agent 调用 Netstars Token API，发现账户余额低于阈值（500 Token）。自动触发充值流程，无需人工介入

2

通过 X402 + USDC 完成充值

Agent 向 Netstars X402 网关发起支付请求，Wea Japan 在 Solana 链上完成 USDC 划转（<1秒确认），Token 余额自动到账

3

使用 Token 调用 AI 服务

Agent 消耗 Token 调用 Claude API 完成商品分析，每次调用实时扣减 Token，并记录到 Netstars 计费系统

4

商户查看账单与链上凭证

通过 Netstars Dashboard，商户可查看 Token 消耗明细、链上交易哈希、发票，所有操作全程可审计

SECURITY ARCHITECTURE

多层安全保障：加密 × 认证 × 可追溯

🔐

端到端加密

所有 API 通信采用 TLS 1.3；钱包私钥从不离开客户端； 支付签名在本地完成，Netstars 不持有用户私钥

🛡️

多因子鉴权

API Key + HMAC 签名双重验证；支持 OAuth 2.0 / JWT； Agent 身份通过 DID（去中心化标识）绑定

🔗

链上不可篡改存证

每笔支付交易哈希写入 Solana 公链，任何人可验证； 防止双花攻击，结算纠纷有链上仲裁依据

📋

全程审计日志

操作日志 90 天留存；支持监管合规导出； 异常交易实时告警，支持自动冻结账户保护

⚡

限流与风控

每个 Agent 独立速率限制；异常消耗模式检测； 支持白名单 IP / 黑名单 DID 管理

🔄

模块化隔离架构
