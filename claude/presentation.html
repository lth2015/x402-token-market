THE SHIFT

传统支付场景

人发起 · 大额 · 一次性

  • · 一次性购买、页面跳转、人工确认
  • · 按订单结算、按月对账
  • · 适合商品交易，不适合 Agent 在调用中连续付费
Agentic Commerce 新需求

Agent 发起 · 微额 · 持续 · 自治

  • · 单次调用价值很小（次/分/秒级）
  • · 高频、连续、无人值守
  • · 支付状态必须即时返回
  • · 资金和数据要留痕、可对账
经营视角的结论： 谁能把支付授权 + Token 库存 + 调用计费 + 结算票据放进同一个商户服务包， 谁就最有机会成为 Agent Commerce 的支付基础设施入口。 这正是 Netstars 已有牌面能直接落地的方向。
事实依据：Coinbase 于 2025-05 正式发布 x402 协议（HTTP 402 + 链上稳定币支付的开放标准）； Anthropic 于 2025-11 在 Claude Agent SDK 中将 x402 作为推荐的 Agent 支付方案。 来源：Coinbase 官方博客 / Anthropic 文档。

REVENUE MODEL · 怎么赚钱

四个收入流，叠加形成稳定现金流

①
Token 销售毛利
来源：商户为 AI 调用付费
企业客户用 USDC/日元购买 AI Token，Netstars 从模型供应商批发后转售。
毛利杠杆：批量采购折扣、套餐溢价、多模型组合定价
②
支付网关服务费
来源：每笔 X402 支付按比例或固定费率
商户使用 X402 + USDC 支付时，Netstars 收取网关处理费 — 即"链上的 Stripe 费率"。
毛利杠杆：高频小额场景天然放大笔数；MCP 接口让 Agent 自主发现，降低获客成本
③
商户 SaaS / 运营管理费
来源：商户购买管理后台 + 多账户 + SLA 套餐
Console、子账户管理、自动充值、告警、自定义报表打包为月费/年费订阅。
毛利杠杆：边际成本极低，ARR 复购稳定，便于估值
④
结算与对账增值服务
来源：财务/审计部门付费购买
链上凭证导出、合规报表、自动对账、跨链多资产汇总 — 大型客户单独付费。
毛利杠杆：仅大客户购买，高客单价；与日本会计软件集成形成网络效应
四流叠加的意义：①是交易型（随 AI 用量增长）； ②是通道型（随 Agent 普及指数增长）； ③是订阅型（稳定 ARR）； ④是高客单价型（拉高平均毛利）。四个曲线叠加 = 抗周期。

RISKS & MITIGATIONS

三个最可能被质疑的风险 — 我们的应对

01

合规与监管

风险：日本金融厅对稳定币和加密资产的监管仍在演进，未来可能要求额外牌照或限制。
应对：① 链上执行外包给 Wea Japan，Netstars 自身保持 Web2 PSP 定位；② 法务部前置审阅每个新场景；③ 与金融厅保持沟通通道（已有上市公司背书）。
02

链上风险与客户损失

风险：Solana 网络拥堵、USDC 脱锚、客户私钥丢失等会直接影响商户体验和资金安全。
应对：① 多 RPC 节点冗余 + 自动切换；② 监测稳定币锚定，异常自动暂停；③ 私钥不离开客户端，损失边界限于客户自身；④ 提供保险方案选项。
03

商户教育成本

风险：日本企业对加密支付与 Agent 自主消费仍有顾虑，签约周期可能比预期长。
应对：① 用"日元发票 + 像 Stripe 一样使用"的话术消除区块链感知；② 灯塔商户案例作为信任锚；③ 设置"上限阈值/熔断"功能让财务安心；④ 与会计系统集成降低对接成本。
