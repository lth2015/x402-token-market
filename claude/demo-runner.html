5 分钟演示剧本

  1. 打开 HABA 首页 → Hero / MARVIE 商品库 / 5 场景 AI Advisor 一眼到位 Go
  2. 点任一场景的 真打一次 → 真 LLM 调用 / Token 扣减 / TopBar 余额掉 Go
  3. 去 /topup 点 真打一笔 → 看 8 步动画 + 真 tx hash 入账 Go
  4. 加几件商品到购物车，去 /cart 走 USDC 钱包结账 → 订单号 + 链上 tx Go
  5. 切到 Netstars Console → Live Activity Ticker 上看到刚才所有事件 Go
  6. 加分项：/agent 跑 "自动 topup" 剧本 → 机器人 12 次连续调用 + 自动补 Token Go
